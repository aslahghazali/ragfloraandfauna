01 / Abstract

What this project explores

This project explores how retrieval-augmented generation (RAG) can help identify flora and fauna references in selected jungle and wildlife writing. The Python file records extracted labels under five source texts: Jungle Folk, A Bird Calendar for Northern India, The Jungle Book, The Wonders of the Jungle, and Beast and Man in India.

The entries offer an exploratory index for further reading about how nature is represented in these texts. The source file explicitly marks the exported AI answers as unverified, so the lists should be treated as candidate extractions rather than confirmed evidence.

02 / Research question

Questions for the study

Primary question

How can RAG support the discovery of flora and fauna references across selected Indian jungle and wildlife texts?

Interpretive question

How should extracted references be checked when an answer can mix species, metaphor, culture, and contextual inference?

03 / Methods

From text to candidate list

The attached script contains five source-specific pairs of lists. Each pair is labelled as a flora extraction and a fauna extraction, with notes in some entries that indicate uncertainty or interpretation. The exported script does not include the underlying prompts, retrieved passages, model settings, or a verification record.

05 / Limitations

What needs checking

Unverified AI output

The source itself says the lists were copied from exported AI answers and are unverified. Claims must be checked against the original passages.

Category errors

Some flora lists contain animals or metaphorical references; fauna lists include people, deities, objects, and broad group labels.

Ambiguous references

Common names, historical spellings, implied mentions, and culturally specific terms can make entity identification uncertain.

Method details absent

The file does not record the prompts, retrieval corpus, chunking, model, source editions, or human validation procedure.
